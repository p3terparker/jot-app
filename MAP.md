# Jot menu bar app — MAP (where everything lives)

A quick-capture notepad whose **Share** menu sends a note anywhere. Native AppKit chrome. **Current: v3.2 (32) — sidebar folders (`Sources/Folders.swift`); see `docs/AUDIT.md` ▸ Jot 3.1 and the Jot 3.0 part log. Notion, Drafts and Rich Text editing are gone; the header, formatting bar, sidebar, editor, windows and Settings were rebuilt in 3.0, and the rows below describe the code as it stands (rows marked (3.0) are new).**
The UI lives in `main.swift`; Foundation storage and frontmatter live in `NoteStorage.swift`. See `docs/FEATURES.md`
for the user-facing feature list/changelog — this file maps features to code.

## 2. Top-level types (by responsibility)

### Prefs persistence
| Type | Role |
|------|------|
| `enum Prefs` | All settings live in `Prefs.d` (`UserDefaults.standard`, or a private suite in a preview):  hotkey (keyCode/carbon/display), `fontSize`, `sidebarShown`, `editorBGHex`, `fontFamily`, `detached` (tray vs. normal window), `launchAtLogin`, `hasShownWelcome`, `toolsShown`/`showAdvancedTools` (formatting bar), and `show.<id>` flags for the Share-menu entries (default on). |

### Per-note metadata (YAML frontmatter)
| Type · function | Role |
|---|---|
| `struct NoteMeta` | Per-note metadata: `pin`, `order` (manual sort, within the note's folder), `folder` (sidebar folder name, `""` = none; written quoted — `folder: "Work"`; cleaned by `FolderNames.clean`), `reminder` (Date?) — plus legacy `priority`, `textColor` and `rtfMode`, still parsed and written back so nothing is lost. `rawLines` + `lineEnding` hold the frontmatter exactly as found: **saves patch those lines** (Jot's keys updated in place, a value that didn't change keeps the author's spelling, keys at their default dropped, new keys appended; everything else — Obsidian `tags:`, comments, lists, nested YAML, blank lines — kept verbatim; CRLF stays CRLF). Only column-0 `key:` lines are Jot's. `hasForeignContent` = the author wrote something Jot doesn't own; `isDecorated` = anything deliberately set **excluding** `order` (drives `isBlankNote`, so a note carrying hand-written frontmatter is never swept as blank). |
| `parseFrontmatter(_:) -> (meta, body)` | Parses `---` delimited YAML block; returns `NoteMeta` + body string (frontmatter stripped). No-closing-delimiter → treats whole file as body (backward compatible). |
| `formatFrontmatter(_:) -> String` | Serializes `NoteMeta` back to a `---` block. Empty meta (no fields set) → empty string (no frontmatter written). |
| `metaDateFormatter` | `ISO8601DateFormatter` for the `reminder` field. |

### Rich text (export only) and the legacy-RTF migration
| Type · function | Role |
|---|---|
| `markdownToRichText(_:baseFont:color:)` | Markdown → `NSAttributedString` for the RTF and HTML **exports** (`exportAttributed` → `writeNote`): styles with `MarkdownStyler`, then copies the kept characters as attributed runs, dropping concealed emphasis markers, heading `#`s and backticks. (Never build a string from `String(ns.character(at:))` — that is the character's number; see GOTCHAS.) Part 6.0 replaces it with the scanner-based renderer. |
| `enum LegacyRTF` (`LegacyRTF.swift`) | Jot ≤ 2.9's per-note Rich Text mode stored base64 RTF with `rtfMode: true`. `migrate(_:)` runs once at launch before any editor loads: for each such note it writes a **byte-identical backup** (`…/Jot/Backups/RTF/<timestamp>/`, plus a plain `.rtf` copy), **reads the backup back**, then rewrites the note as Markdown with `rtfMode` removed and its modification date kept; any failure leaves the note untouched. `toMarkdown(_:)` maps font size → heading level, bold/italic runs → `**`/`*`, links → `[t](u)`. `AppDelegate.announceLegacyRTF` tells you once (alert; replaced by a toast in Part 4.2). |

### Editor / text view
| Type · function | Role |
|---|---|
| `final class JotTextView: NSTextView` | The editor widget. `insertTab`/`insertBacktab` → `reindent` (2-space markdown indent) or table cell navigation (`moveToNextCell`/`moveToPrevCell` if cursor is in a `|...|` row). `keyDown` → ⌥↑/⌥↓ `moveLines`, ⌘D `duplicateLines`, **⌘⇧ arrows** (sidebar nav: ←/→ open/close, ↑/↓ prev/next note). `mouseDown` → `toggleCheckbox` (click `[ ]`/`[x]` to toggle). `insertNewline` continues markdown list/checkbox markers (`listMarker`) or ends the list on an empty item. |
| `final class MarkdownStyler: NSObject, NSTextStorageDelegate` | Live markdown rendering: regexes for `#` headings, `**bold**`/`__bold__`, `*italic*`/`_italic_`, `` `code` ``, **checkbox markers** (`[x]` green, `[ ]` dim), **table separator lines** (`|---|` dim). `textStorage(_:didProcessEditing:)` → `restyle` the edited paragraph; `styleAll` restyles everything; `style`/`emphasize`/`trait` apply the attributes. The `revealRange` **property** holds the paragraph under the cursor whose raw `**`/`*` markers stay visible for editing — elsewhere they're concealed (the property is set by `revealActiveParagraph`). |
| `final class ConcealLayoutDelegate: NSObject, NSLayoutManagerDelegate` (singleton `concealLayoutDelegate`) | Makes glyphs tagged `.jotConceal` zero-width/non-drawing, so the bold/italic markers visually disappear while the underlying text stays real plain-text markdown. Shared by every editor (docked + undocked). |
| `func revealActiveParagraph(_:_:)` | Shared helper: re-styles only the paragraph that changed (old + new cursor location) when the cursor moves, so markers reveal/conceal cheaply. Called from both the docked and undocked editors. |

### Notes storage
| Type · function | Role |
|---|---|
| `final class NotesStore` | One `.md` file per note (with optional YAML frontmatter). `all()` lists all notes in the notes directory. `create()` creates a new note. `read` returns body only (strips frontmatter); `readMeta(_:)` returns parsed `NoteMeta`; `write` preserves existing frontmatter; `writeMeta` rewrites frontmatter only. Both reject unreadable existing files and report errors through `onWriteError`. `saveExisting` throws on failed reads/writes and never creates a missing note; editor autosaves use this path. `create` throws on failure. `isUndecoratedBlank` refuses to classify unreadable files as empty. `delete(_:)` moves a note to `trashDir` (Recently Deleted) — **not** the system Trash — stamping mod-date as deletion time. `delete` and `restore` throw on failed moves; delete never falls back to unlinking the original. `trashedAll()`, `deletedDate`, `restore(_:)`, `deletePermanently(_:)` (system Trash), `purgeTrash(olderThanDays:)` (called at launch, 30-day default). |

## 3. Isolated preview and walkthrough (Jot 3.0)
`./preview.sh [Jot.app] [outdir]` runs the **built** bundle with `--jot-preview --jot-preview-snapshots <dir>` and a throwaway `HOME`. `Runtime` (Preview.swift) swaps in a private defaults suite (`com.jacob.jot.preview`), a temporary notes folder filled from `Fixtures.swift`, a private pasteboard, and skips the hotkey, login item, status item and **UserNotifications** (all access goes through `notificationCenter()`; pending reminders are per bundle ID and are shared with the live app). Senders (Apple Notes, Stickies, Save, Share) are recorded in `PreviewLog` instead of performed; every window is parked off-screen and nothing activates. `PreviewWalkthrough` scripts the real UI, writes PNGs (+ a solid stand-in for the glass) and `walkthrough.txt` (`expect` = hard check, `probe` = observation) and exits non-zero unless the last line is `PREVIEW WALKTHROUGH OK`. `--jot-preview` alone shows the pad on screen with the fixtures. Any new shortcut, window rule or storage behaviour gets an `expect` there.

## 4. Common tweaks (then `./build.sh`)
- **Default hotkey:** `Prefs.hotkeyKeyCode` (runtime: Preferences ▸ Change Hotkey).
- **Which Share-menu entries show:** Preferences ▸ "Show in the Share menu" (per-entry toggles).
- **Editor font size / family:** Preferences ▸ Editor, or View ▸ Bigger / Smaller / Actual Size (⌘+ ⌘− ⌘0). The formatting bar no longer carries them.
- **Window translucency:** `makeGlassContentView().material`.
- **Recently Deleted retention:** `store.purgeTrash(olderThanDays: 30)` in `applicationDidFinishLaunching`.

## 5. Caveats
- Apple Notes uses AppleScript (Automation, one-time prompt). **Stickies' system Service is dead
  on current macOS** — Jot falls back to keystrokes, which need **Accessibility permission for
  Jot** specifically, and that grant only survives rebuilds under a stable signing identity
  (`./build.sh --identity NAME`, or `JOT_SIGNING_IDENTITY`; don't gate logic on `AXIsProcessTrusted()` — it
  reads false under ad-hoc signing even when access is granted). See `GOTCHAS.md`.
- Jot makes **no network requests** (`test.sh` fails if a network API appears in the sources).

## 6. Regression checks and current boundaries

Run `./test.sh` (Foundation-only: storage, frontmatter passthrough/CRLF/nested YAML, `NoteLibrary` ordering and filtering, `HotkeyDefaults`, fixtures, the legacy-RTF migration and its converter) and `./preview.sh` (the AppKit side: key routing, window rules, menus, hotkey registration, isolation, the RTF export read-back, accessibility labels, timings, snapshots). Together they use only temporary notes, defaults suites and pasteboards.

Not covered: real VoiceOver speech, macOS 13–15 appearance (the host is macOS 26), Intel, multi-display/Spaces behaviour, real Apple Notes / Stickies delivery, a real mouse drag, disk-full conditions and crash recovery. Normal quit is flushed; a process crash can still lose the debounce interval.
