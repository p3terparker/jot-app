# Jot 3.0 (30) — first standalone preview

The first standalone, open-source Jot release. Jot lives in the macOS menu bar: press a shortcut, type, and the note is saved as a plain Markdown file on your Mac.

## Download and install

1. Download **Jot.dmg** below (about 2 MB).
2. Open it and drag **Jot** to **Applications**.
3. Eject the disk image and open Jot. Click the note icon in the menu bar or press **Option–Command–J**; the first note explains the rest.

**This preview is ad-hoc signed and not notarized by Apple.** If macOS blocks the first launch, try opening Jot, then go to **System Settings → Privacy & Security → Open Anyway**. Do not disable system security. If that option is unavailable, this installer may not be usable on your Mac.

## What's in 3.0

- **Live Markdown.** Headings, bold, italic, strikethrough, links, `code`, checklists, quotes and tables look formatted as you type; markers hide except at the caret. ⌘/ shows the plain text. A formatting bar with Apple Notes shortcuts toggles each style.
- **A notes list** that is a drawer over the text on a small pad and docks beside it on a wide one, with search (⌥⌘F), pins, multi-select, drag to reorder, and Recently Deleted (30 days) with Undo.
- **Share anywhere.** Apple Notes, Stickies, Save As (txt, md, rtf, html, paginated PDF), the system Share sheet, or Copy. Failures say what happened.
- **Native note windows, reminders, a welcome note and a compact Settings window.** New installs use Option–Command–J; an install that never chose a shortcut keeps Control–J.
- **Safer with your files.** Notes are plain `.md` files; frontmatter Jot doesn't own (for example Obsidian tags) is kept untouched; deleting offers Undo.
- **Removed:** Notion, Drafts sync and the per-note rich-text editing mode. Existing rich-text notes are converted to Markdown at launch after a verified byte-identical backup; rich text remains an export format.
- **Private.** No network access and no account.

The full list and changelog are in [docs/FEATURES.md](../FEATURES.md).

## Permissions

Apple Notes asks once for Automation permission. Stickies needs Accessibility permission for Jot; without it Jot copies the note, opens Stickies and says what to press. Reminders need notification permission, which macOS asks for when you set the first one.

## Requirements and verification

Requires macOS 13 or newer. The app includes Apple Silicon and Intel slices. Verification passed 26 tooling tests, 97,623 Swift regression checks and a 247-check isolated AppKit walkthrough (also on the Intel slice under Rosetta and on a hardened-runtime build), plus a clean-clone build and a build made while the original project folders were unreadable, and mounted-DMG validation. **Real Intel hardware, macOS 13–15, VoiceOver, and real Apple Notes and Stickies delivery in other languages remain manual acceptance gaps.**

Jot's source is MIT licensed and contains no third-party code.
